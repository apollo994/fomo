# FOMO ablation study

*2026-10-15 · branch `ablation` · code at `2bf111c` · 23 Lycaenidae species, all-vs-all*

This study switches off FOMO's components one at a time and measures what each one is worth
for the lncRNA deliverable. It has two parts:

- **Part A (offline):** the curation rule, the reference filter and the donor set,
  re-evaluated from the chains of an existing full run.
- **Part B (pipeline re-runs):** seven re-runs, each with one component switched off.

All tables quoted here are regenerated by `scripts/summarize.py` into
[`tables/summary_tables.md`](tables/summary_tables.md); per-target values are in `tables/*.tsv`.

---

## Key findings

1. **The consensus rule is the component that matters.** Requiring an intron chain in ≥ 2
   species (`--curate_min_species 2`):
   - removes 99.9 % of decoy chains, against 86.5 % of real ones;
   - raises precision 2.7× (3.7 → 10.1 %) at the cost of half the sensitivity (15.7 → 8.4 %);
   - gives the best lncRNA F1 of any threshold.

   Precision rises steadily with support, from 2 % for a chain seen in 1 species to 68 % for one
   seen in 10–14. The best threshold depends on the feature type: mRNA's F1 keeps improving up
   to k ≈ 3–5 (32.8 → 39.5).
2. **The choice of donors matters more than any switch inside the pipeline.** Donors are
   ranked per target by a truth-free distance, the median `de` of their projected mRNA. When
   ≥ 2 congeneric donors exist (16 of 23 targets), both of these beat the current consensus
   over all 22 donors (median F1 17.9; Sn 18.1, Pr 17.9 %):
   - the **4 nearest donors at k = 2**: F1 24.0, with **Pr 50.5 %** and Sn 15.5 %;
   - the **single nearest donor**, no consensus: F1 26.1 (Sn 23.0, Pr 30.3 %).

   With a fixed k = 2, adding distant donors adds noise faster than signal: precision falls
   with every donor added, while sensitivity is already at its plateau after the 12 nearest.
   Per target, the single nearest donor is the best of the options tried in 12 of 23 targets,
   the 4-nearest consensus in 5 and the current default in 6 (appendix).
   - lncRNA transfers far worse than mRNA with distance: the median single-donor lncRNA F1 is
     28 % at `de` < 0.02 and < 6 % in every bin beyond (mRNA: 50 → 34 → 24 %). But the
     *Lycaena* congeners reach F1 ≈ 30 at `de` ≈ 0.037, so `de` ranks donors well within a
     target, while an absolute cut-off does not carry over between genera.
3. **The reference filter removes 45 % of supported chains** (17,345 of 38,934). About a
   third of the removed chains are exact copies of annotated lncRNA isoforms (5,710), so
   the filter works as intended. The same-strand default matters: filtering on both strands
   would delete a further 44 % of the curated output.
   - Curated genes are enriched for `antisense_exonic`: 45 %, against a median of 26 % of
     annotated lncRNAs.
   - These antisense chains are not strand flips: only 20 of 38,934 share any intron with an
     opposite-strand annotated transcript.
4. **TD2 does little to the deliverable.** Switching off both passes changes curated output
   by only +1.5 % and F1 by −0.13. TD2 removes only ~10 % of the supported lncRNA chains that
   sit on annotated coding exons; 19.7 % of supported chains still overlap an mRNA exon.
   - For annotated targets the reference filter removes these chains anyway.
   - For **unannotated** targets it is a real gap. In an offline test, masking with projected
     mRNA (≥ 2 species) would catch 73 % of these chains.
   - The input TD2 pass is nearly redundant with the projected pass for the deliverable
     (+0.6 % curated without it).
5. **`--longest_isoform` (default on) is a mild, consistent win for precision.** Turning it
   off projects 12 % more sequences and yields 9 % more curated transcripts. Sn rises in every
   target, Pr falls in every target, and F1 falls by 0.36 for targets with congeners.
6. **`--include_single_exon` has no effect on any result.** It adds 203,279 single-exon models
   (+55 % of the raw file), but benchmarking (`gffcompare -M`) and curation both drop
   single-exon models, so no number changes.
7. **minimap2:** keep `-uf`. `-ub` is slightly worse in almost every target and lets 10 % more
   decoys through curation. **`splice:hq`** runs alignment ~2.5× faster, but the effect on
   accuracy depends on the target:
   - targets with close donors: F1 +0.57 (precision up in 16 of 16);
   - targets without: F1 −0.75 (down in 7 of 7).
8. **The decoy FDR is not a usable FDR for curated output.** Decoys from different donors almost
   never share a chain, so the ≥ 2-species rule removes them by construction. The estimate
   therefore reads < 1 %, while only 10–15 % of supported chains reproduce an annotated
   isoform. The run summary's `est_curated_fdr_pct` also compares a reference-filtered real
   track with an unfiltered decoy track, which is why it reads up to 175 % for mRNA.

### Verdict per component

| component | how it was ablated | effect of removing it | verdict |
|:---|:---|:---|:---|
| consensus ≥ 2 species | `--min-species` 1…12 (offline) | k = 1: decoys ×780, Pr 10.1 → 3.7 %, F1 8.5 → 5.2 | **essential**; tune per feature type |
| donor set (all sources) | nearest / farthest / random / congener subsets (offline) | where congeners exist, nearest 1 (k = 1) or nearest 4 (k = 2) beat all 22 by +8.2 / +6.1 F1 | **biggest lever**; make it adaptive |
| reference filter, same strand | `--ref` on/off, `--strand both` (offline) | it removes 45 % of supported chains, all on annotated loci; `both` would remove a further 44 % of curated transcripts | keep; keep `same` |
| input TD2 | `--psauron-min 1.01` (input stage) | curated +0.6 %, F1 −0.01 | redundant for the deliverable; defines the reference |
| projected TD2 | `--psauron-min 1.01` (projected stage) | curated +0.6 %, F1 −0.03 | keep (cheap); weak coding guard |
| both TD2 passes | both stages | curated +1.5 %, F1 −0.13, mRNA-identical chains +31 % | keep; add an mRNA mask for unannotated targets |
| longest isoform | `--longest_isoform false` | +12 % input, +9 % curated, F1 −0.20 | keep (default) |
| single-exon drop | `--include_single_exon true` | +55 % raw models, no effect downstream | option has no effect; remove or document |
| `-uf` strand constraint | `-ub` | F1 −0.05, curated decoys +10 % | keep |
| `splice` preset | `splice:hq` | −10 % curated, ~2.5× faster; +F1 close / −F1 far | candidate option for close-donor designs |

## 1. Set-up

### Data and reference run

The **reference run** is `thirsty_linnaeus` (session `3098a02f…`, 2026-10-15):

```
-profile crg --include_mrna --include_decoy
```

over the 61-species Lycaenidae samplesheet. Its **23 `role: both` species** (full Ensembl/NCBI
assemblies and Ensembl annotations) are the donors and the benchmarked targets. Every target
therefore receives 22 donors, ranging from congeners (*Lycaena*, *Aricia*, *Lysandra*) to other
subfamilies (*Satyrium*, Theclinae). Filtered lncRNA references contain 967–6,681 transcripts
per target.

### Part A — offline

For every target and track, `bin/curate_models.py` (in the pipeline's own CURATE_MODELS
container) was re-run on the published `allModels.<track>.raw.gff3` with these flags:

```
--min-species 1 --chains-tsv          # once without --ref, once with it
```

The `--chains-tsv` audit table lists every intron chain with its supporting species, its status
after the reference filter, and the reference biotypes it touched. From one such table, any
support threshold and any donor subset can be scored without re-running curation.

### Part B — re-runs

Each configuration ran the 23-species samplesheet with `--include_decoy` (lncRNA + its decoy
track). It resumed a **copy** of the reference run's cache against the same work directory, so
only what the switched-off component changes was recomputed (0.3–7.9 CPU-h per configuration).
Overrides live in `configs/`.

| config | change |
|:---|:---|
| B0 | none (resumed, 1,106 of 1,154 tasks cached) |
| B1 | `--longest_isoform false` |
| B2 | input TD2 filter off (`--psauron-min 1.01`) |
| B3 | projected TD2 filter off |
| B4 | both TD2 filters off |
| B5 | `--include_single_exon true` |
| B6 | minimap2 `-x splice -ub --cs` |
| B7 | minimap2 `-x splice:hq -uf --cs` |

### Scoring

The unit of scoring is the **intron chain** (multi-exon, stranded, exact coordinates). This is
what curation clusters on, and it is what gffcompare's transcript level matches on under `-M`.

| yardstick | contents |
|:---|:---|
| **strict** | the pipeline's own benchmarking reference, `<target>.lnc_RNA.filtered.gff3` (longest isoform, TD2-noncoding), **always taken from the reference run**, so B1/B2/B4, which change the reference, are scored on the same ruler |
| **lenient** | every stranded multi-exon `lnc_RNA` of the samplesheet GFF3 (all isoforms, no TD2) |

- Sn = annotated chains recovered ÷ annotated chains. Pr = predicted chains that match ÷
  predicted chains.
- Values are **medians over the 23 targets** unless marked *sum* or *pooled*.
- Precision against an annotation is a **lower bound**: unannotated real lncRNAs count as
  errors.
- *Decoy chains* are chains of the relocated-decoy track that pass the same rule.

### Validation of the set-up

- **B0 reproduces the reference run exactly:** all 69 lncRNA outputs compared (allModels raw,
  decoy raw, allModels gffcompare stats) are byte-identical. Resuming hit the cache for 99 % of
  tasks, which also shows the current code is what produced the reference run.
- **The chain metric matches gffcompare:** chain-level Sn at k = 1 equals the pipeline's
  `allModels_raw` transcript-level Sn in **46 of 46** (target, track) pairs.
- **The offline curation matches the pipeline:** chains with ≥ 2 species surviving the
  reference filter equal the pipeline's curated transcript count in **46 of 46** pairs.

### 2.3 Donor set

Donors are ranked per target by the **median `de` of their projected mRNA** on that target.
This ranking needs no annotation of the target: it picks the single best donor (by F1) in 16
of 23 targets, and the best donor is among the 3 nearest in 22 of 23.

| donor set | Sn strict | Pr strict | F1 strict |
|:---|---:|---:|---:|

- With a fixed k = 2, **precision falls steadily as donors are added**: 59.9 → 50.5 → 35.0 →
  23.8 → 17.9 % for 2 → 4 → 6 → 8 → 22 donors. Any two of 22 mostly distant species agree by
  chance far more often than the two nearest ones do. Sensitivity has reached its plateau by
  the 12 nearest donors.
- The current rule is therefore not scale-invariant: the same `--curate_min_species 2` is
  stricter in a 3-donor run than in a 22-donor run.
- Random subsets confirm that the gain comes from *which* donors are used, not from how many:
  random 4-donor subsets give F1 2.0 at k = 2.
- Where no close relative exists, consensus cannot recover sensitivity. The single nearest donor
  is then the best, and still poor, option.

### 2.4 Divergence

*Accuracy of each single (target, donor) pair, from the pipeline's per-source gffcompare*

| median `de` of the donor | pairs | lncRNA F1 (median) | mRNA F1 (median) |
|:---|---:|---:|---:|
| < 0.02 | 14 | 27.7 | 50.2 |
| 0.02–0.04 | 28 | 5.9 | 33.9 |
| 0.04–0.06 | 40 | 2.7 | 24.4 |
| 0.06–0.10 | 98 | 2.7 | 24.6 |
| ≥ 0.10 | 326 | 0.7 | 11.1 |

Spearman correlation of F1 with `de`: −0.84 for lncRNA and −0.88 for mRNA. The same-genus
median lncRNA F1 is 11.8, against 1.1 for other genera. LncRNA structure transfers well only
between close species, and it degrades much faster than mRNA as divergence grows.

The bins hide one exception. The *Lycaena* congeners sit at `de` ≈ 0.036–0.039 yet reach
single-donor F1 ≈ 30, while *Aricia morronensis* and *A. nicias*, at `de` 0.021–0.038, stay
near 5. So `de` is a good *ranking* within a target, but an absolute cut-off does not carry
over between genera. Annotation depth also differs between species (§6).

### 2.5 Reference filter

*lncRNA, k = 2, sums over targets*

| supported chains | kept (curated) | lost to the reference | lost: identical to an annotated lncRNA isoform | lost: identical to an annotated mRNA isoform | lost: touch an mRNA exon |
|---:|---:|---:|---:|---:|---:|
| 38,934 | 21,589 | 17,345 | 5,710 | 977 | 7,636 |

- Of the supported chains that land on a known lncRNA (primary type `lnc_RNA`: 9,709),
  **59 % reproduce an annotated isoform exactly**. Where FOMO can be checked, its chain
  structures are mostly right.
- **Strand of the overlap test** (`--strand both`, re-curated at k = 2): curated transcripts
  fall from 21,589 to 12,192 (−44 %). The genes removed are the `antisense_exonic` class:
  - 9,302 of 20,865 curated genes (45 %) are `antisense_exonic`, against a median of 26 %
    (13–30 %) among each target's annotated lncRNAs (`tables/A2_antisense_annotated.tsv`);
  - only 20 supported chains, across all targets, share even one intron with an
    opposite-strand annotated transcript, while 13,725 share one on the same strand
    (`tables/A2_strand_flip.tsv`).

  So they are not strand-flipped copies of annotated genes. Keep `same`. The enrichment is
  worth a manual look before these models are released.

### 2.6 Coding contamination (unannotated targets)

The reference filter hides it for annotated targets. A pure `target` with no gff3 receives
every supported chain:

- **19.7 %** of supported lncRNA chains (7,652 of 38,934) touch an annotated same-strand mRNA
  exon;
- **977** of them are identical to an annotated mRNA isoform.

TD2 as configured (`--complete-orfs-only`) removes only ~10 % of this contamination
(section 3).

What-if: drop lncRNA chains that overlap the exons of projected mRNA models supported by ≥ M
species. Scored against annotated mRNA exons, pooled over the 23 targets
(`tables/A6_mrna_mask.tsv`):

|:---|---:|---:|---:|
| M = 1 | 93.4 % | 39.3 % | 11,043 (35 %) |
| **M = 2** | 73.2 % | 53.2 % | 4,932 (16 %) |
| M = 3 | 52.2 % | 59.8 % | 2,690 (9 %) |

Every Part B effect is small, so the medians over 23 targets barely move. The paired
per-target deltas below show whether the direction is consistent. "16↑ / 0↓" means the value rose in 16 targets
and fell in none.

**B1 — longest isoform off.**
- Sn rises in every target: +0.66 with congeners (16↑ / 0↓), +0.12 without (7↑).
- Pr falls in every target: −1.32 (16↓) and −0.33 (7↓).
- Strict F1 −0.36 for targets with congeners; lenient F1 is roughly neutral (+0.22 and +0.13).
- The extra isoforms add mostly redundant or alternative chains, and 9 % more curated
  transcripts.
- It also enlarges the benchmarking reference by 12 % (56,731 vs 50,553). The pipeline's own
  `allModels_raw` Sn therefore *drops* from 15.7 to 14.6, an artefact of the moving yardstick
  that the fixed yardstick avoids.
- **Keep the default.**

**B2–B4 — TD2.**
- The input pass removes 801 source lncRNAs (1.6 %). The projected pass removes 4,161 projected
  models (1.1 %), and 10,326 when the input pass is off (B2): the projected pass catches most
  of what the input pass would have removed. So **the input pass is redundant for the
  deliverable** (curated +0.6 %, F1 ±0). Its real role is to define the TD2-filtered
  benchmarking reference (plans/20).
- With both passes off (B4), Pr falls in all 23 targets, but only by 0.62 (congeners) and 0.21
  (others).
- The lenient F1 *rises* in all 23 targets (+0.36 with congeners, +0.39 without). Annotated
  lncRNAs that carry a complete ORF are recovered, and the lenient yardstick counts them as
  correct.
- Chains identical to an annotated mRNA isoform go from 977 to 1,276 without TD2. TD2 catches
  23 % of these and 10 % of the chains that touch coding exons. This is the weak spot behind
  §2.6: `--complete-orfs-only` cannot flag fragments of coding genes.
- TD2 is cheap (~0.1 CPU-h per pass for 23 targets). **Keep it, but do not rely on it as the
  only coding guard.**

**B5 — single-exon models.**
- 203,279 single-exon models are added to `allModels.lnc_RNA.raw.gff3`.
- Every number downstream is identical: gffcompare runs with `-M` and `curate_models.py` drops
  single-exon models.
- The option only inflates the published raw file and the projected TD2 input.
- **Remove it, or document that it changes only the raw file.**

**B6 — `-ub` instead of `-uf`.**
- F1 falls slightly in nearly every target (k = 1: 23 of 23).
- Decoys get through more easily: +3.9 % at k = 1 and +10 % among curated decoys.
- Decoy-track alignment takes ~11 % longer.
- **Keep `-uf`**: spliced transcripts have a known strand.

**B7 — `splice:hq`.**
- Stricter alignment scoring: −7 % raw models, −10 % curated transcripts, −16 % decoy chains
  at k = 1 and −19.5 % curated decoys.
- Alignment wall time per target is 0.38× the baseline's (median) for lncRNA and 0.70× for
  decoys. Against B6, which ran at the same time: 3,010 s vs 6,954 s summed over targets (lncRNA track).
- The effect splits by donor distance:
  - targets with congeners: Pr +0.88 (16↑ / 0↓) and **F1 +0.57 (14↑ / 2↓)** at k = 2;
    at k = 1, Sn rises too;
  - targets without: **F1 −0.75 (7↓)**, through lost sensitivity.
- **A good option when close donors exist** (e.g. a `--minimap2_preset` param, or chosen from
  the donor `de`); not a better default for a mixed clade.

## 4. A finding about the evaluation instruments

The **decoy track does not estimate the false-discovery rate of curated output.** Each donor's
decoys are relocated independently into its own intergenic space. Two donors' decoys therefore
almost never share an exact chain on the target, so the ≥ 2-species rule removes them by
construction:

- decoy chains surviving k = 2: 0.13 %, against 13.5 % of real chains;
- the estimated FDR is < 1 % at every k ≥ 2;
- yet only 10.6–12.6 % of 2–3-species chains reproduce an annotated isoform (§2.2).

The decoys model one error mode, random sequence that happens to align. They are blind to
errors that several donors share: coding fragments, paralogs, conserved non-lncRNA
transcription. The few decoys that do reach k ≥ 2 mostly come from pairs of close relatives
(e.g. the *Lysandra* trio). Treat the decoy FDR as a lower bound.

The run summary's `est_curated_fdr_pct` is also biased, upwards. It divides
the decoy rate, which the reference filter does not touch, by the real rate *after* the
reference filter, which removes 45 % of lncRNA chains and 96 % of mRNA chains. Over the 23
targets it reports 2.8–175 % for mRNA (and 0–12 % for lncRNA).

Two better instruments are already available:

- the support calibration (§2.2);
- the share of supported chains that reproduce known isoforms or overlap coding exons
  (§2.5–2.6).

## 5. Recommendations

1. **Make the donor set adaptive (highest impact).** Rank donors by median `de`, which the
   pipeline can compute from its own alignments, and curate over the nearest N. N ≈ 4 is
   expected to give +6 F1 points, mostly precision (Pr 18 → 50 %), for targets with
   congeners.
   - Alternatively, weight support by proximity, or scale `curate_min_species` with the
     number of donors.
   - Keep "all donors" as the fallback for targets without close relatives. A rule that
     worked here is "nearest 4 when ≥ 2 donors are congeneric, else all". A `de` cut-off
     would be more general, but no single value worked across genera (§2.4).
   - Also publish the single nearest donor's projection as a high-recall companion: it is
     already written as `<target>.from_<donor>.lnc_RNA.projected.gff3`, and it had the best
     F1 in 12 of 23 targets.
2. **Use per-track thresholds**, e.g. `curate_min_species` 2 for lncRNA and ~4 for mRNA if the
   mRNA track is ever delivered.
3. **Mask coding loci for unannotated targets** with the projected mRNA track (≥ 2 species
   catches 73 % of coding contamination). This would make `--include_mrna` part of the
   deliverable for pure targets. Otherwise, document that ~20 % of their curated lncRNA
   chains overlap coding exons.
4. **Keep** `--longest_isoform`, `-uf`, both TD2 passes and the same-strand reference filter.
   Dropping the input TD2 pass would change the deliverable by only +0.6 %, but it defines
   the benchmarking reference, so leave it unless that changes.
5. **Remove or re-document `--include_single_exon`**: it has no downstream effect.
6. **Offer `splice:hq`** as an option, or choose it automatically when the nearest donor is
   close. It is ~2.5× faster to align and more precise for close donors.
7. **Do not report the decoy FDR of curated output as an FDR.** Replace it with the support
   calibration, or fix the estimator so both tracks go through the same reference filter.
8. **Review the `antisense_exonic` class** (45 % of curated genes) before release. It is not
   a strand artefact, but it is 1.7× the rate among annotated lncRNAs.

## 6. Limitations

- One clade (Lycaenidae, 23 benchmarked species) and one annotation source (Ensembl).
  Targets are not independent (shared donors, phylogeny), so medians and per-target sign
  counts are reported, not p-values.
- **The yardsticks are annotations.** Precision is a lower bound, and annotation depth varies a
  lot. *P. szabokyi* has 6,681 filtered lncRNAs against 967–1,577 for *Lycaena*, which caps
  measurable Sn for close pairs such as *P. icarus* / *P. szabokyi*.
- Matching is exact by intron chain: there is no partial credit and terminal exons are ignored.
  Single-exon models are invisible to every metric here, as they are to the pipeline's own
  benchmarking.
- Part B ablates one component at a time (no interactions), on lncRNA + decoys only. The mRNA
  positive control was not re-run for B1/B6/B7.
- Components not ablated:
  - self-projection (already studied in plans/23);
  - the merge/split of plans/15 (lossless by design);
  - keeping secondary or supplementary alignments (would need a change to `bam_to_gff.sh`);
  - `decoy_cap` and the other minimap2 parameters.
- The donor ranking uses median `de` from the same run's mRNA projections. It is truth-free,
  but needs the mRNA track or a first alignment pass.
- Wall times come from a shared cluster and vary between nodes. Ratios between configurations
  that ran concurrently (B6 vs B7) are the more reliable comparison.

## 7. Reproducing

Everything lives in `ablation/`:

| path | contents |
|:---|:---|
| `configs/` | override configs for B2–B4, B6, B7 |
| `scripts/` | scripts that launch, extract and score the runs |
| `tables/` | per-target TSVs and `summary_tables.md` |

Raw outputs are on scratch (not backed up): `/nfs/scratch01/rg/fzanarello/fomo_ablation/`,
with `runs/B*/results` for the re-runs and `offline/` for the chain tables. Total compute was
~23 CPU-h for Part B plus ~2–3 CPU-h for Part A.

```sh
# from the repository root, inside a SLURM allocation that may submit jobs (-profile crg)
S=ablation/scripts
ABL=/nfs/scratch01/rg/fzanarello/fomo_ablation   # samplesheet_both23.csv = the 23 'both' rows
REF=/users/project/phyloENCODE_009142_no_backup/general_analyses/crossmapping/fomo_runs/lycaenidae/results
WORK=/nfs/scratch01/rg/fzanarello/work_fomo
SHEET=$ABL/samplesheet_both23.csv
CFGS=(B1_no_longest B2_no_input_td2 B3_no_proj_td2 B4_no_td2 B5_single_exon B6_minimap2_ub B7_minimap2_splicehq)

# Part B: B0, then B1–B7 side by side. Each resumes a copy of the reference run's cache.
$S/run_config.sh B0_baseline
$S/launch_part_b.sh

# Chain audit tables: reference run (Part A, also used for B0), then each B configuration
$S/chains_for_run.sh $REF $ABL/offline/full_chains $SHEET 'lnc_RNA lnc_RNA.decoy mRNA mRNA.decoy' 8
$S/chains_part_b.sh

# Part A: sweep, calibration, donors, per-source (written to $ABL/offline/A*.tsv)
$S/run_part_a.sh
$S/strand_both.sh $REF $ABL/offline/strand_both $SHEET
python3 $S/strand_both_table.py $SHEET $REF $ABL/offline/strand_both   > $ABL/offline/A2_strand_both.tsv
python3 $S/antisense_rate.py $SHEET $REF                               > $ABL/offline/A2_antisense_annotated.tsv
python3 $S/strand_flip.py $SHEET $ABL/offline/full_chains lnc_RNA 2    > $ABL/offline/A2_strand_flip.tsv
python3 $S/mrna_mask.py $SHEET $REF $ABL/offline/full_chains 2 1 2 3   > $ABL/offline/A6_mrna_mask.tsv

# Part B: scoring on the fixed yardsticks, coding overlap, cost
runs=(B0_baseline:$ABL/runs/B0_baseline/results:$ABL/offline/full_chains)
ovl=(B0_baseline=$ABL/offline/full_chains)
trc=(B0_baseline=$ABL/runs/B0_baseline/results/pipeline_info/execution_trace.txt)
for n in "${CFGS[@]}"; do
    runs+=($n:$ABL/runs/$n/results:$ABL/offline/chains_$n)
    ovl+=($n=$ABL/offline/chains_$n)
    trc+=($n=$ABL/runs/$n/results/pipeline_info/execution_trace.txt)
done
python3 $S/ablate.py configs --sheet $SHEET --fixed-results $REF --runs "${runs[@]}" --out $ABL/offline/B_configs.tsv
python3 $S/coding_overlap.py $SHEET 2 "${ovl[@]}"                      > $ABL/offline/B_coding_overlap.tsv
python3 $S/trace_cost.py $WORK "${trc[@]}"                             > $ABL/offline/B_cost.tsv
python3 $S/align_times.py $WORK B0=$REF/pipeline_info/execution_trace.txt \
    B6=$ABL/runs/B6_minimap2_ub/results/pipeline_info/execution_trace.txt \
    B7=$ABL/runs/B7_minimap2_splicehq/results/pipeline_info/execution_trace.txt > $ABL/offline/align_times.tsv

# Collect the tables and render the summary
cp $ABL/offline/{A,B}*.tsv $ABL/offline/align_times.tsv ablation/tables/
python3 $S/summarize.py ablation/tables > ablation/tables/summary_tables.md
```
